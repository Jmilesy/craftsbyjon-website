Gelato Intake
Attaches the real print-ready files (the masters) to your existing Gelato products and records which file prints on which variant. Files are stored privately on the server, never on the public image folder, and never shown on the store. Nothing on this page sends anything to Gelato or places an order. To create a brand new design first, use POD Intake.
1. Choose the print files
Drop a whole set at once (you can select the files from all three folders together). Each file is matched to a design and a slot from its name: Anchor.png (mug), Anchor_T-Shirt Dark.png / Light.png, Anchor_Poster-with-text.png / no-text.png. Nothing uploads until you press the button in step 2.
Click to choose or drag PNG files here
2. Check and upload
Each cell is one file. Green means it is already stored. Files are checked before upload: mugs must be 2410 × 1182 px and t-shirts 3600 × 4800 px (the confirmed Gelato sizes), posters must be square. A file that would replace one already stored is skipped unless you tick the box below.
3. Which file prints on which variant
An order can only be prepared automatically when its variant is mapped to a file that exists. Anything unmapped stays a manual order, so nothing is ever guessed.
T-shirts: by shirt colour
Dark file has the cream text (for dark shirts). Light file has the dark charcoal text (for light shirts). Pre-filled from your answer on 28 Sep 2026: Navy and Rs Sport Grey use Dark, White, Natural and Sand use Light. Check it, it applies to all t-shirt designs.
Mugs
Each mug is one white ceramic variant, so every mug variant uses its design's single mug file.
Posters and prints
Posters can be uploaded above and are kept safe, but they cannot be mapped yet. The text / no-text choice does not exist on the print products (they only have Size), so there is nothing to say which file a customer's order should use. This needs the Text option built into the store first. Until then print orders stay manual.
4. Where things stand
For each product: how many variants are ready (mapped to a stored file), missing a file, or not mapped yet.
